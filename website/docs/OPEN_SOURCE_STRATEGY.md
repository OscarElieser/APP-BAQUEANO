# ESTRATEGIA DE CÓDIGO ABIERTO (OPEN SOURCE STRATEGY)

## 1. Principio Fundamental: Open Data $\neq$ Open Source Todo el Código

Baqueano distingue con claridad entre la apertura de datos e interfaces y la apertura del código fuente:
- **Componentes Abiertos (Open Source)**:
  - SDKs de integración oficial (TypeScript/JavaScript).
  - Ejemplos de integración y componentes cívicos de mapas.
  - Esquemas de validación Zod y definiciones de GeoJSON.
- **Componentes Propietarios / Núcleo Protegido**:
  - Modelos de riesgo y motores de inferencia de Baqueano AI.
  - Lógica interna de conciliación de reservas y pagos.
  - Reglas de seguridad y llaves de cifrado de infraestructura.
