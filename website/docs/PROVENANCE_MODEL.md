# MODELO DE PROCEDENCIA DE DATOS & UMBRALES DE FRESCURA

## 1. Tipos de Fuentes (*Source Types*)
- `OFFICIAL`: Entidades gubernamentales, decretos y cartografía oficial.
- `BAQUEANO_VERIFIED`: Inspeccionado por el equipo de campo Baqueano.
- `VERIFIED_PARTNER`: Organismo aliado auditado.
- `COMMUNITY`: Conocimiento oral o registro comunitario ancestral.
- `BUSINESS_SELF_REPORTED`: Datos suministrados por el titular sin validar en campo.
- `SYSTEM_DERIVED`: Cálculos geoespaciales o agregaciones del sistema.
- `AI_DERIVED`: Inferencias de modelos IA (nunca equivalen automáticamente a verificado).
- `UNKNOWN`: Fuente no rastreada.
