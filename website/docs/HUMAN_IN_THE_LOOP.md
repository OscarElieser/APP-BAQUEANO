# PROTOCOLO HUMAN-IN-THE-LOOP (HITL)

## 1. Principio Fundamental
La inteligencia artificial es una herramienta de asistencia y preparación, no una autoridad delegada. Toda decisión que impacte reservas, finanzas, identidades, verificación o reputación de prestadores requiere validación y consentimiento humano explícito.

## 2. Prevención de Fatiga de Confirmación (*Approval Fatigue*)
No se solicita confirmación para operaciones de lectura o preparación de borradores (Nivel 0 y 1). Las solicitudes de confirmación se reservan para escrituras reversibles (Nivel 2) y acciones de impacto sensible (Nivel 3).
