# FINOPS & CONTROL DE COSTOS EN WORKFLOWS MULTIAGENTE

## 1. Eficiencia de Modelos & Enrutamiento
- Tareas de clasificación de intenciones y formateo: modelos ligeros y rápidos.
- Tareas determinísticas (distancias, presupuestos, filtros): ejecutadas 100% en código TypeScript sin coste de tokens.
- Consultas culturales complejas: invocación con RAG vectorial acotado a fragmentos relevantes.

## 2. Presupuesto de Tokens por Workflow
Cada workflow tiene un techo estricto de tokens de entrada y salida para evitar costos imprevistos o recursiones innecesarias.
