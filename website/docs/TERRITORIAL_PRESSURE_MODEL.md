# MODELO MATEMÁTICO DEL ÍNDICE DE PRESIÓN TERRITORIAL

## 📐 1. Fórmula de Ponderación Oficial

$$Presión = (Demanda \times 0.35) + (Capacidad \times 0.30) + (VulnerabilidadAmbiental \times 0.20) + (Estacionalidad \times 0.15)$$

Donde cada factor se normaliza en una escala continua de `[0.0, 1.0]`.

---

## 🚦 2. Escala Semántica de Presión

- `0 a 39` → **LOW (Presión Baja / Ocupación Holgada)**
- `40 a 64` → **MODERATE (Presión Moderada / Equilibrio)**
- `65 a 84` → **HIGH (Presión Alta / Alerta Preventiva)**
- `85 a 100` → **CRITICAL (Presión Crítica / Sobrecarga Inminente)**

> [!NOTE]
> Alta presión territorial no significa automáticamente daño ambiental, sino una señal para evaluar la distribución de guías y horarios de visita.
