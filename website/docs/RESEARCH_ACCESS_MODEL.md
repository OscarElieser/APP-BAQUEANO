# MODELO DE ACCESO PARA INVESTIGACIÓN CIENTÍFICA & UNIVERSIDADES

## 1. Niveles de Acceso para Investigación (Research Tiers)

| Nivel | Descripción | Requisitos | Datasets Disponibles |
| :--- | :--- | :--- | :--- |
| **Tier 1: Open Research** | Acceso público sin registro | Ninguno | Destinos, territorios, patrimonio cultural y red de Smart Points públicos. |
| **Tier 2: Registered Student** | Proyectos de tesis de pregrado | Correo institucional `.edu` verificado | Datasets históricos agregados y cuota ampliada de API. |
| **Tier 3: Approved Scientific** | Investigaciones formales de posgrado y ONGs | Propuesta metodológica aprobada por el comité científico | Telemetría ambiental agregada (clima, calidad de aire, nivel de ríos) con K-anonymity. |
| **Tier 4: Restricted / Longitudinal** | Convenios interinstitucionales con ministerios | Acuerdo de confidencialidad y gobernanza formal | Estudios de capacidad de carga de largo plazo. |
