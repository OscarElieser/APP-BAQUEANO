# DNS CONFIGURATION

## Why

El dominio oficial debe apuntar al hosting correcto sin inventar IPs ni registros.

## How

Registrar solo valores entregados por la plataforma final de hosting.

## What

Canonical recomendado si el dominio esta adquirido y aprobado: `https://www.baqueano.ni`.

| Host | Tipo | Valor | Estado |
|---|---|---|---:|
| `www.baqueano.ni` | PENDIENTE | Proveedor hosting debe generarlo | PENDIENTE |
| `baqueano.ni` | PENDIENTE | Redirigir al canonical elegido | PENDIENTE |
| `admin.baqueano.ni` | PENDIENTE | Proveedor hosting debe generarlo | PENDIENTE |
| Verificacion dominio | TXT | Proveedor debe generarlo | PENDIENTE |

No se verifico DNS ni certificado SSL en esta fase.
