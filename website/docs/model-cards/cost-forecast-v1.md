# MODEL CARD: COST FORECAST V1 (`cost-forecast-v1`)

## 📋 Resumen del Modelo
- **Propósito**: Proyectar costos mensuales de infraestructura Cloud (Firestore, AI Gateway, Maps y Compute) con alertas preventivas.
- **Versión**: `v1.0.1`
- **Algoritmo**: Extrapolación de run-rate ponderado con picos estacionales de calendario.
- **Métricas de Rendimiento**: MAE: 11.5 USD | MAPE: 6.8%.
