# MODEL CARD: CAPACITY FORECAST V1 (`capacity-forecast-v1`)

## 📋 Resumen del Modelo
- **Propósito**: Calcular la tasa de utilización y nivel de saturación comunitaria (LOW, MODERATE, HIGH, VERY_HIGH, UNKNOWN).
- **Versión**: `v1.1.0`
- **Algoritmo**: Ratio determinístico de demanda proyectada sobre capacidad validada en censo local.
- **Métricas de Rendimiento**: MAE: 5.2% | MAPE: 7.1%.

## 🚫 Usos Prohibidos
- Prohibido para sobrecargar a cooperativas campesinas por encima de su capacidad máxima declarada.
