# REGISTRO DE CAMBIOS DE LA API (API CHANGELOG)

## Versión 1.0.0 — Septiembre 2026 (Fase 13)

- **Lanzamiento de Open Data API v1 (`/api/open/v1/*`)**:
  - Endpoint de destinos públicos con soporte GeoJSON RFC 7946 (`/api/open/v1/places`).
  - Endpoint de territorios y divisiones político-administrativas (`/api/open/v1/territories`).
  - Endpoint de tótems y señalética inteligente (`/api/open/v1/smart-points`).
  - Endpoint de catálogo de datasets y descargas en JSON y CSV (`/api/open/v1/datasets`).
- **Lanzamiento del Portal de Datos Abiertos (`/open-data`)**.
- **Lanzamiento del Developer Portal (`/developers`)** con explorador interactivo.
- **Lanzamiento de la Plataforma de Investigación Científica (`/research`)**.
- **Consola de Administración de Clientes API (`/desarrolladores`)** en el panel administrativo.
