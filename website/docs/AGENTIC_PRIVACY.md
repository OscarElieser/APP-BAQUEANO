# PRIVACIDAD EN EL SISTEMA AGENTIC

## 1. Minimización de Datos en Contexto
Los agentes solo reciben la información estrictamente necesaria para resolver la intención actual (territorio, días, grupo, presupuesto y estilo de viaje). Queda prohibido inferir atributos personales sensibles (salud, religión, política u orientación).

## 2. Control de Memoria por el Usuario
El explorador dispone de un botón permanente de **"Nueva Planificación"** para purgar el contexto de la sesión actual de forma instantánea.
