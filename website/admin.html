Política de Protección y Resiliencia

• Principio Rector: Firebase es el sistema primario. Supabase mantiene el resguardo relacional y geoespacial.
• Conmutador Circuit Breaker: Monitoreo continuo de conectividad para desviar solicitudes a cola de contingencia local.
• Resiliencia de Datos: Diseñado para minimizar pérdida de datos mediante cola de contingencia y respaldo secundario.
• Integridad de Archivos: Hash SHA-256 verificado en cada replicación entre buckets.
