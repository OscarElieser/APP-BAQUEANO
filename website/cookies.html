Política de Cookies, Almacenamiento Local y Caché Offline

Transparencia tecnológica para una experiencia rápida, segura y funcional, incluso cuando el viajero se encuentre sin conexión a Internet.

BAQUEANO NICARAGUA utiliza determinadas tecnologías de almacenamiento técnico para mantener sesiones, recordar preferencias, mejorar el rendimiento y permitir que algunas funcionalidades continúen disponibles en zonas con conectividad limitada.

Nuestro principio es sencillo:

01

¿Qué son las Cookies y el Almacenamiento Local?

Las cookies son pequeños archivos o identificadores que un sitio web puede almacenar temporalmente en el navegador para mantener determinadas funciones.

BAQUEANO también puede utilizar otras tecnologías de almacenamiento local, como:

  • LocalStorage
  • SessionStorage
  • IndexedDB
  • caché del navegador
  • almacenamiento seguro de Android
  • caché interna de la aplicación
  • archivos o recursos descargados para funcionamiento offline.

Estas tecnologías pueden utilizarse para recordar información como:

  • idioma seleccionado
  • moneda preferida USD/NIO
  • sesión iniciada
  • preferencias de navegación
  • destinos consultados
  • favoritos
  • estado temporal del cotizador
  • configuraciones de visualización
  • información previamente descargada para uso offline.
02

Cookies y Almacenamiento Técnicamente Necesarios

Algunas tecnologías de almacenamiento son necesarias para que determinadas funciones operen correctamente.

Pueden utilizarse para:

  • mantener sesiones autenticadas
  • gestionar accesos mediante Firebase Authentication
  • proteger formularios y solicitudes
  • mantener temporalmente información del cotizador
  • recordar configuraciones esenciales
  • conservar el estado de determinadas pantallas
  • detectar comportamientos técnicos anómalos
  • prevenir accesos indebidos o determinadas formas de abuso
  • mejorar estabilidad y rendimiento.

Estas tecnologías no tienen como finalidad crear perfiles publicitarios del usuario.

Cuando un elemento sea estrictamente necesario para prestar un servicio solicitado, su desactivación puede impedir que determinadas funciones operen correctamente.

03

Preferencias del Usuario

BAQUEANO puede almacenar preferencias básicas para evitar que el usuario tenga que configurarlas cada vez que utiliza la plataforma.

Por ejemplo:

Idioma

Español o inglés.

Moneda

Córdobas nicaragüenses (NIO) o dólares estadounidenses (USD).

Configuración territorial

Preferencias relacionadas con mapas, destinos o contenido visualizado.

Interfaz

Preferencias de visualización cuando esta funcionalidad esté disponible.

Estas configuraciones pueden permanecer almacenadas hasta que el usuario las modifique, elimine los datos de la aplicación o borre el almacenamiento del navegador.

04

Caché de Contenido y Rendimiento

BAQUEANO puede almacenar temporalmente determinados recursos con el objetivo de acelerar la plataforma y reducir el consumo innecesario de datos.

Esto puede incluir:

  • imágenes
  • iconos
  • archivos de interfaz
  • información turística previamente consultada
  • recursos multimedia optimizados
  • resultados temporales
  • fichas de destinos
  • elementos cartográficos permitidos por los proveedores correspondientes.

El caché permite que la aplicación cargue más rápido y reduzca solicitudes repetitivas a los servidores.

Los datos almacenados pueden renovarse, actualizarse o eliminarse automáticamente cuando dejen de ser necesarios.

05

Almacenamiento Offline para Exploración Territorial

Una de las funciones principales de BAQUEANO es facilitar el acceso a información útil incluso en zonas donde la conexión móvil sea limitada o inexistente.

Cuando técnicamente esté disponible y el usuario utilice estas funciones, la aplicación podrá almacenar localmente determinados recursos previamente descargados, como:

  • fichas de destinos
  • rutas guardadas
  • información territorial
  • coordenadas
  • puntos previamente consultados
  • números de emergencia
  • información básica necesaria para exploración offline
  • recursos cartográficos permitidos para almacenamiento local.

El almacenamiento offline permite consultar información previamente descargada sin depender permanentemente de una conexión a Internet.

06

Mapas y Datos Cartográficos

Los mapas utilizados por BAQUEANO pueden depender de proveedores tecnológicos externos.

La disponibilidad de descarga, almacenamiento offline, imágenes satelitales, capas cartográficas y otros recursos estará sujeta tanto a las funcionalidades implementadas por BAQUEANO como a las condiciones técnicas y de licencia del proveedor correspondiente.

Por esta razón, BAQUEANO no almacenará ni redistribuirá contenido cartográfico cuando las condiciones del proveedor no lo permitan.

07

Geolocalización y Almacenamiento

La geolocalización no se activa automáticamente mediante una cookie.

Cuando una función requiera conocer la ubicación del usuario, el navegador o dispositivo Android solicitará el permiso correspondiente.

La ubicación podrá utilizarse para funciones como:

  • mostrar lugares cercanos
  • centrar el mapa
  • calcular rutas
  • utilizar funciones del Centro SOS
  • proporcionar información territorial contextual.

BAQUEANO no necesita utilizar cookies publicitarias para acceder a la ubicación del dispositivo.

El usuario puede modificar los permisos de ubicación desde la configuración de su navegador o dispositivo.

08

Funcionamiento en Android

La aplicación Android de BAQUEANO puede utilizar mecanismos distintos a las cookies tradicionales de un navegador.

Dependiendo de la funcionalidad implementada, puede utilizar:

  • almacenamiento local de la aplicación
  • bases de datos internas
  • caché
  • almacenamiento seguro para determinadas credenciales o identificadores
  • archivos descargados
  • preferencias internas
  • servicios de autenticación.

Estos mecanismos permiten que la aplicación mantenga determinadas configuraciones y mejore su funcionamiento.

Los datos almacenados localmente pueden eliminarse utilizando las opciones correspondientes del sistema Android o mediante funciones internas de BAQUEANO cuando estén disponibles.

09

Cookies o Servicios de Terceros

Algunas funcionalidades pueden depender de proveedores tecnológicos externos.

Esto puede incluir servicios relacionados con:

  • autenticación
  • mapas
  • infraestructura cloud
  • protección de seguridad
  • notificaciones
  • reproducción de contenido
  • inteligencia artificial.

Estos proveedores pueden utilizar tecnologías técnicas propias cuando sean necesarias para prestar sus servicios.

BAQUEANO procurará limitar estas integraciones a aquellas que sean necesarias para el funcionamiento de la plataforma.

Cuando una tecnología requiera consentimiento adicional conforme a su naturaleza o finalidad, BAQUEANO podrá solicitar autorización previamente.

10

Cero Publicidad Basada en Rastreo

BAQUEANO NICARAGUA no utiliza su plataforma con el objetivo de construir perfiles publicitarios invasivos sobre sus usuarios.

Esto significa que BAQUEANO no pretende utilizar cookies para:

  • vender historiales de navegación
  • seguir al usuario entre múltiples sitios web con fines publicitarios
  • crear perfiles comerciales basados en ubicaciones
  • compartir patrones individuales de viaje con redes publicitarias
  • comercializar información de navegación.

BAQUEANO tampoco utiliza deliberadamente cookies publicitarias de terceros para campañas de publicidad programática basadas en el comportamiento personal del usuario.

11

Analítica y Mejora Técnica

BAQUEANO podrá utilizar información técnica agregada o herramientas de diagnóstico destinadas a mejorar:

  • velocidad
  • estabilidad
  • rendimiento
  • compatibilidad
  • seguridad
  • detección de errores
  • experiencia general del usuario.

Siempre que sea técnicamente posible, se procurará minimizar la recopilación de información personal y utilizar métricas agregadas o datos técnicos limitados a las finalidades de funcionamiento y mejora.

12

Duración del Almacenamiento

La duración del almacenamiento dependerá de la finalidad de cada elemento.

Algunos datos podrán mantenerse:

Durante la sesión

Se eliminan o dejan de ser necesarios al cerrar la sesión o navegador.

Temporalmente

Se conservan durante un período determinado para mejorar el rendimiento.

Hasta que el usuario los elimine

Por ejemplo, determinadas preferencias o contenido descargado.

Hasta que sean actualizados automáticamente

Por ejemplo, caché, información territorial o recursos temporales.

BAQUEANO evitará conservar información local durante más tiempo del razonablemente necesario.

13

¿Cómo Puede el Usuario Administrar estos Datos?

El usuario mantiene control sobre gran parte del almacenamiento local de su dispositivo.

Puede:

  • borrar cookies desde el navegador
  • eliminar datos almacenados por un sitio web
  • limpiar caché
  • eliminar contenido offline
  • cerrar sesión
  • revocar permisos
  • eliminar datos de la aplicación Android
  • desinstalar la aplicación
  • restablecer determinadas preferencias.

La eliminación de estos datos puede provocar que:

  • sea necesario iniciar sesión nuevamente
  • se pierdan preferencias guardadas
  • desaparezca contenido offline
  • determinados destinos deban descargarse nuevamente
  • algunas funcionalidades temporales se reinicien.
14

Consentimiento y Configuración

Cuando BAQUEANO utilice exclusivamente tecnologías estrictamente necesarias para prestar funciones solicitadas por el usuario, estas se utilizarán únicamente con finalidad técnica.

Si en el futuro BAQUEANO incorpora categorías adicionales que no sean estrictamente necesarias —por ejemplo, analítica avanzada, personalización opcional o tecnologías de terceros adicionales— deberá proporcionar mecanismos adecuados de información y configuración.

Cuando corresponda, el usuario podrá:

Aceptar

Autorizar las categorías opcionales.

Rechazar

Mantener únicamente las tecnologías esenciales.

Configurar

Seleccionar individualmente las categorías permitidas.

15

Cambios en esta Política

Esta política podrá actualizarse cuando:

  • se incorporen nuevas funcionalidades
  • cambie la tecnología de almacenamiento
  • se integren nuevos proveedores
  • se modifique la aplicación Android
  • cambien servicios de mapas
  • se incorporen nuevas funcionalidades offline
  • exista una modificación normativa aplicable.

Las modificaciones relevantes serán reflejadas en esta misma sección.
