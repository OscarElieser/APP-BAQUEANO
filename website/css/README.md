# Organización CSS

## POR QUÉ

Evitar estilos duplicados y permitir encontrar rápidamente colores, tipografía,
estructura, componentes y reglas exclusivas de una página.

## CÓMO

- Fundamentos: `colors.css`, `typography.css` y `layout.css`.
- Componentes compartidos: `components.css`, `modules.css` y archivos temáticos.
- Vistas concretas: `pages/<pagina>.css`.
- Compatibilidad histórica: `../styles.css`, conservado en la raíz pública.

## QUÉ

Antes de crear un selector, revisar si ya existe un token o componente equivalente.
Los colores oficiales son `#165D6F`, `#F65E01`, `#F4E6C1` y `#0F172A`.
